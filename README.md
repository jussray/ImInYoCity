# I'M IN YO CITY • PHILLY AFTER DARK

**Original Juss & Co. browser 3D action-adventure vertical slice.** A standalone Philly game, not a renamed Pittsburgh build.

## Current playable slice

- Procedural WebGL Philadelphia-inspired neighborhood with recognizable City Hall tower, Reading Terminal-inspired market, LOVE Park-inspired plaza, riverfront bridge, South Philly rowhouses, moving traffic and pedestrians.
- Third-person character, joystick and camera follow/rotate, keyboard WASD, desktop mouse-look, jump, fly/land, and non-violent electric pulse.
- Four story beats: Meet Nova, reach Reading Terminal, activate the rooftop relay, disable three roaming signal drones. Mission journal, map, reputation, audio, and pause/restart.
- Responsive portrait and landscape UI, self-hosted graphics with no CDN or paid assets. Android packaging scaffold included but NOT built, signed, or Google Play approved.

This is a **stylized first playable vertical slice**, not a PS5-quality production game or geographically accurate city scan. All world meshes are generated by original game code. Landmarks are artistic approximations, not official business endorsements.

## Play and verify

```bash
python3 -m http.server 8080
# http://localhost:8080
python3 tests/verify_game.py
node scripts/build.mjs
```

Use Chromium/WebGL-enabled browser and Python Playwright for the browser test. The Playwright proof is local viewport emulation, **not** device GPU, store publishing, or production proof.

## Android / Google Play gate

`capacitor.config.json` and `package.json` are a packaging starting point, **not** evidence of an Android release. To submit to Google Play: verify app identifier ownership; install dependencies in an authorized build environment; run `npm run build`, `npx cap add android`, `npx cap sync`; test touch input, audio, WebGL, accessibility, power usage, and graphics on physical Android devices; generate app icons/splash and legal/ratings/privacy disclosures; produce and sign an AAB; perform Play Console policy and target-SDK review. Do not ship until reviewed and approved.

## Production standard

Keep screenshots of start **and live gameplay** separate from concept art. The Godot/Unreal/Unity-style fidelity goal needs proper authored meshes, PBR materials, lighting pipeline, asset-provenance/rights, and mobile GPU profiling beyond this no-dependency baseline. Do not imply reference imagery represents engine runtime. Preserve proof receipts, exact repo SHA and reversible changes. FCR Games Hub should link this repository using a reviewed mapping, not a new command center.
