# I'M IN YO CITY • PHILLY AFTER DARK

**Original Juss & Co. browser 3D action-adventure vertical slice.** A standalone Philly game, not a renamed Pittsburgh build.

## Current playable slice

- Procedural WebGL Philadelphia-inspired neighborhood with recognizable City Hall tower, Reading Terminal-inspired market, LOVE Park-inspired plaza, Fairmount's Philadelphia Museum of Art silhouette, riverfront bridge, South Philly rowhouses, moving traffic and pedestrians.
- Third-person character, joystick and camera follow/rotate, keyboard WASD, desktop mouse-look, jump, fly/land, and non-violent electric pulse.
- Four story beats: Meet Nova, reach Reading Terminal, activate the rooftop relay, disable three roaming signal drones. Mission journal, map, reputation, audio, and pause/restart.
- Responsive portrait and landscape UI, self-hosted graphics with no CDN or paid assets. Android packaging scaffold included but NOT built, signed, or Google Play approved.

This is a **stylized first playable vertical slice**, not a PS5-quality production game or geographically accurate city scan. All world meshes are generated by original game code. Landmarks are artistic approximations, not official business endorsements.

## Play and verify

```bash
python3 -m http.server 8080
# http://localhost:8080
python3 tests/verify_game.py
python3 tests/verify_service_worker.py   # served sw.js: updates reach players, offline still boots
python3 tests/verify_camera_clearance.py # camera never inside buildings; flight/landing respect roofs
node scripts/build.mjs
```

Use Chromium/WebGL-enabled browser and Python Playwright for the browser test. The Playwright proof is local viewport emulation, **not** device GPU, store publishing, or production proof.

## Physical Android phone verification

After installing Android Platform Tools and Python packages `Pillow` and
`websocket-client` on your own computer, connect an authorized Android phone
by USB with debugging permitted, then run:

```bash
adb devices
python3 tests/verify_android_emulator.py --physical --apk /path/to/app-debug.apk
# Add --serial DEVICE_ID only if multiple devices are connected.
```

The script rejects emulators and multiple unselected ADB devices, installs
the **debug** APK on the selected phone, launches its Capacitor WebView,
replays joystick/camera/mission/Sky Mode interactions, checks actual WebGL,
and saves `artifacts/android-phone/{result.json,title.png,gameplay.png,controls-tested.png}`.
The report contains an APK hash and non-unique model/Android version, but
never a device serial or system logcat. Keep screenshots local until reviewed.
WebView-injected gestures verify the app's touch handling; a person must still
judge actual finger responsiveness, audio, device temperature and battery
performance. A physical PASS is not Play Store approval or release signing.

## Android / Google Play gate

`capacitor.config.json` and `package.json` are a packaging starting point, **not** evidence of an Android release. To submit to Google Play: verify app identifier ownership; install dependencies in an authorized build environment; run `npm run build`, `npx cap add android`, `npx cap sync`; test touch input, audio, WebGL, accessibility, power usage, and graphics on physical Android devices; generate app icons/splash and legal/ratings/privacy disclosures; produce and sign an AAB; perform Play Console policy and target-SDK review. Do not ship until reviewed and approved.

## Production standard

Keep screenshots of start **and live gameplay** separate from concept art. The Godot/Unreal/Unity-style fidelity goal needs proper authored meshes, PBR materials, lighting pipeline, asset-provenance/rights, and mobile GPU profiling beyond this no-dependency baseline. Do not imply reference imagery represents engine runtime. Preserve proof receipts, exact repo SHA and reversible changes.
